# TASK-ID — Tên Task

## Thông tin Task

Ghi Task ID, tên, Sprint và nguồn. Liên kết đến trạng thái trong Sprint Backlog.

## Objective

Ghi kết quả Task cần đạt.

## Related Requirements

Liên kết Requirement ID, Use Case và tài liệu thiết kế liên quan.

## Dependencies

Ghi Task ID, hợp đồng và môi trường cần có.

## Scope

Liệt kê các deliverable.

## Out of Scope

Ghi các hạng mục lân cận thuộc Task khác.

## Implementation Requirements

Ghi ràng buộc cụ thể. Dẫn nguồn cho yêu cầu đã có trong tài liệu.

## Acceptance Criteria

Liệt kê kết quả quan sát được để nghiệm thu.

## Testing Requirements

Ghi test cần chạy, môi trường và bằng chứng cần lưu.

## Definition of Done

Kiểm chứng tiêu chí bắt buộc và liên kết Development Report.

## Development Report Reference

Liên kết báo cáo khi có.
