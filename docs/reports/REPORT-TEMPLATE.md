# Tên Task

## 1. Thông tin Task

- Task ID
- Tên Task
- Sprint
- Ngày triển khai (YYYY-MM-DD hoặc `UNKNOWN`)
- Trạng thái (`COMPLETED` / `PARTIAL` / `BLOCKED`)
- Yêu cầu liên quan
- Loại báo cáo và nguồn bằng chứng (ghi ngay sau triển khai hoặc khôi phục)

## 2. Tóm tắt triển khai

Ghi phạm vi đã thực hiện và kết quả.

## 3. File thay đổi

Ghi đường dẫn tương đối từ repository root.

## 4. Quyết định kỹ thuật

Ghi các quyết định có ảnh hưởng đến triển khai và lý do.

## 5. Kết quả kiểm chứng

| Check | Command or Evidence | Status |
|---|---|---|
|  |  |  |

## 6. Acceptance Criteria

| Criterion | Status | Notes |
|---|---|---|
|  |  |  |

## 7. Vấn đề và blocker

Ghi lỗi còn mở, blocker, technical debt và giới hạn bằng chứng.

## 8. Ghi chú cho developer

Mô tả luồng chính, trách nhiệm từng thành phần, kiến thức cần nắm và file nên review.

## 9. Task tiếp theo

Ghi công việc tiếp theo theo Product Backlog.
