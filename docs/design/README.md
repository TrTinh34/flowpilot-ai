# FlowPilot AI — Design Documentation

Thư mục này chứa toàn bộ tài liệu thiết kế UI/UX của FlowPilot AI, được tạo trong phạm vi **AUTH-08 — Authentication UI/UX Design & Global Design Foundation**.

## Nội dung

Planning Sprint 06 nằm trong [Frontend Audit](frontend/frontend-audit.md), [Visual Direction](frontend/visual-direction.md) và [Screen Specs](frontend/screen-specifications.md). Tài liệu trong thư mục `frontend/` ghi baseline và đề xuất redesign chờ duyệt. Các tài liệu Sprint 04 giữ làm lịch sử.

| File | Mô tả |
|---|---|
| [01-Design-Direction.md](01-Design-Direction.md) | Product visual identity, brand, design principles |
| [02-Design-System.md](02-Design-System.md) | Design tokens, typography, spacing, component conventions |
| [03-Sitemap.md](03-Sitemap.md) | Screen inventory, navigation architecture, routes |
| [04-User-Flows.md](04-User-Flows.md) | Authentication user flows (login, register, error states) |
| [05-Component-Guidelines.md](05-Component-Guidelines.md) | Component architecture, hierarchy, styling guidelines |
| [wireframes/](wireframes/) | Auth screens wireframes (text-based + SVG) |

## Quan hệ với Kiro Spec

Tài liệu này bổ sung (không thay thế) cho [Kiro spec frontend-design-foundation](../../.kiro/specs/frontend-design-foundation/requirements.md). Kiro spec chứa requirements và tasks để implement; docs này chứa rationale và visual direction.
